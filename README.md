# 0854 电子信息 · 考研择校速查表

面向 **27 考研** 的「0854 电子信息」专业学位择校工具：把全国 **147 所院校、1053 个招生方向** 的复试分数线做成一张可筛选、可排序、可打「冲 / 稳 / 保」标签的表。

- 网页版在线体验：<https://y4580482.github.io/0854-kaoyan-selector/>（GitHub Pages）
  备用地址：<https://ee0854-kaoyan.app.workbuddy.host/>
- 安卓离线 App：[Release v1.0](https://github.com/y4580482/0854-kaoyan-selector/releases/tag/v1.0) 下载 APK，或自行编译 `android/` 工程

---

## 为什么做这个

0854 电子信息是考研第一大专业学位类别，但它有两个坑：

1. **同一所学校的不同学院分数天差地别**。东南大学从国家卓越工程师学院的 270 分到信息学院信号与信息处理的 393 分，跨度 123 分；电子科技大学一家就有 58 个招生点。按「学校」汇总看，信息完全失真。
2. **数据散落在上百个学院官网**。复试线通常只在学院《复试录取工作细则》里公布，逐校翻找要花几十个小时。

所以本表的粒度是 **学校 × 学院 × 研究方向**，并把原始来源链接一并附上，方便自行核验。

## 数据口径

| 项目 | 说明 |
|---|---|
| 年份 | **2026 届**（2025 年 12 月初试、2026 年 3 月复试）官方公布的复试分数线 |
| 覆盖范围 | 39 所 985 全部在列 + 74 所 211 + 34 所热门双非（含重邮、杭电、南邮、西邮、桂电、深大等） |
| 专业范围 | 085400 大类及 085401~085412 全部细分方向 |
| 总量 | 1053 个招生方向，其中 981 条有明确分数线 |
| 来源分级 | 官网 / 院系官网直采 **72%**，第三方整理约 21%，未查到约 7%（`source` 字段逐条标注） |
| 分数区间 | 254 ~ 405，全国平均 312、中位数 310 |

### 读表时请务必注意

- **复试线 ≠ 录取线**。差额复试普遍 1:1.2~1:1.5，实际录取最低分通常高于复试线 5~30 分。中南大学自动化学院 2026 年复试线 405，54 个名额有 60 多人上线，有效录取分在 409 左右。
- **校线 ≠ 院线**。只公布校线的院校，表中分数等于校线（`note` 字段注明「校线」），实际院线通常更高。
- **执行国家线**的方向（`note` 注明「执行国家线 A 区 264 / B 区 254」）说明上线压力小，往往还有调剂名额。
- **25 届对比列覆盖率仅 16%**，个别涨幅异常大（如 +77、+111）多半是首年招生或上年执行国家线导致，横向比较时以 26 届绝对分数为准。

## 功能

- **冲稳保自动标注**：填入预估分，按「超线 20+ 保 / 超线 5~20 稳 / 差线 ≤15 冲 / 差线 >15 险」给每个方向打标签
- **多维筛选**：院校层次、专业方向（085401~085412）、难度档、地区/省份、是否考 408 统考
- **快捷场景**：捡漏榜（985/211 里 ≤310 分的方向）、380+ 神仙打架、计算机/软件/AI、集成电路、通信、招生大户（名额 100+）
- **来源可核验**：点开任意一行能看到该条数据的原始官方链接
- **难度色阶**：380+ 深红 → 300 以下绿色，颜色越红越难

## 用法

### 1. 网页版

直接双击 `index.html`，或访问在线地址。手机浏览器也能用，表格可左右滑动。

### 2. 更新数据

不用碰代码，改表即可：

```bash
python update.py export    # all.json → all.csv
# 用 Excel / WPS 打开 all.csv 修改，保存
python update.py check     # 体检：分数越界、代码格式、层次取值
python update.py import    # 回写 all.json 并自动生成 index.html
```

`import` 会自动重算派生字段：`delta`（26届−25届）、`tier`（难度档）、`dirName`、`region`。改了分数，难度档自动跟着变。

需全量重采（如 27 届分数线公布后）时，重新采集写入 `data/*.json`，再跑：

```bash
python build.py && python build_html.py
```

### 3. 安卓离线 App

APK 内已内置全部数据，**装完断网也能查**。最低支持 Android 7.0（API 24）。

自行编译：

```bash
# 准备：JDK 17+，Android SDK（platform-tools / platforms;android-34 / build-tools;34.0.0）
#   修改 build_apk.py 顶部的 SDK 路径
python build_apk.py
```

脚本走的是 `aapt2 → javac → d8 → zipalign → apksigner` 纯命令行链路，**不需要 Gradle 和 Android Studio**，SDK 只需约 250MB。

> 已知坑：JDK 21+ 编译出的**匿名内部类**会让 d8 8.2 抛 `NullPointerException`。工程里已把 `WebViewClient` 写成独立顶层类规避，改代码时请沿用这个写法。

## 数据来源与声明

数据来自各高校研究生招生网、各学院《2026 年硕士研究生复试录取工作细则》等公开渠道，部分院校未能获取院系级分数线的已如实留空，**未做任何推测性填充**。

本表用于横向比较和圈定目标范围。报考请以目标院校当年招生简章与官方公告为准。
