# 考研择校通 · 电子信息(0854) 择校

面向 **27 考研** 的「0854 电子信息」专业学位择校工具：把全国 **147 所院校、1053 个招生方向** 的复试分数线、国家线、各科分数、学费与录取名单做成一张可筛选、可排序、可打「冲 / 稳 / 保」标签的表。

> v5.3 起**每个专业都有和 0854 一模一样的独立详情页**：任意「学校 × 专业」点进去都是整页详情（渐变页头 + 冲/稳/保 + 四张统计卡 + 年份切换 + 考试科目 + 逐年招生/复试线 + 参考书 + 国家线 + **同专业其他院校对比**），不再只有一个小浮层。

> v5.2 起把两个数据源**并集**，真正做到 **「所有专业都能查」**：**研招网硕士专业目录（919 校）∪ 掌上考研（930 校）→ 1047 所院校 × 1,483 个专业代码 × 42,823 条「学校×专业」**（较 v5.1 新增 **5,101 条**只在掌上考研出现的专业、**128 所**只在掌上考研出现的院校）。同时**顶部搜索框现在会直接命中全量专业库**——输入学校 / 专业名 / 专业代码 / 学院都能查到（不限 0854），并兼容「华北电力大学(北京)」↔「华北电力大学」这类**全角括号 / 校区后缀写法差异**。

> v5.1 起把**全国专业库**做到「与 0854 同等详细」：接入**掌上考研**公开数据，为 **930 所院校 / 51,376 个「学校×专业×院系×学习方式」** 补齐 **复试线 · 逐年招生人数 · 考试科目 · 参考书**（其中 **43,410 条有复试线**），不再只是"收录了专业名字"。**任意学校页面都能搜索该校全部专业**。

> v5.0 起新增 **「全国专业库」**：内置**研招网硕士专业目录全量数据**——**919 所院校 × 1,336 个专业代码 × 37,722 条「学校×专业」**，**不再限于 0854**，覆盖哲学、经济、法、教育、文学、理学、工学、农、医、管理、艺术、交叉学科等全部门类，含院系、学位类型、学习方式、拟招生人数与考试科目。

## 为什么做这个

0854 电子信息是考研第一大专业学位类别，但它有两个坑：

1. **同一所学校的不同学院分数天差地别**。东南大学从国家卓越工程师学院的 270 分到信息学院信号与信息处理的 393 分，跨度 123 分；电子科技大学一家就有 58 个招生点。按「学校」汇总看，信息完全失真。
2. **数据散落在上百个学院官网**。复试线通常只在学院《复试录取工作细则》里公布，逐校翻找要花几十个小时。

所以本表的粒度是 **学校 × 学院 × 研究方向**，并把原始来源链接一并附上，方便自行核验。

| 分数区间 | 254 ~ 405，全国平均 312、中位数 310 |

### 读表时请务必注意

- **复试线 ≠ 录取线**。差额复试普遍 1:1.2~1:1.5，实际录取最低分通常高于复试线 5~30 分。中南大学自动化学院 2026 年复试线 405，54 个名额有 60 多人上线，有效录取分在 409 左右。
- **校线 ≠ 院线**。只公布校线的院校，表中分数等于校线（`note` 字段注明「校线」），实际院线通常更高。
- **执行国家线**的方向（`note` 注明「执行国家线 A 区 264 / B 区 254」）说明上线压力小，往往还有调剂名额。
- **25 届对比列覆盖率仅 16%**，个别涨幅异常大（如 +77、+111）多半是首年招生或上年执行国家线导致，横向比较时以 26 届绝对分数为准。

## 用法

### 1. 网页版

直接双击 `index.html`，或访问在线地址。页面按手机 App 布局（底部五个 Tab），电脑浏览器打开会窄屏居中显示，手机浏览器打开即原生手感。

### 2. 更新数据

不用碰代码，改表即可：

```bash
python update.py export    # all.json → all.csv
# 用 Excel / WPS 打开 all.csv 修改，保存
python update.py check     # 体检：分数越界、代码格式、层次取值
python update.py import    # 回写 all.json 并自动生成 index.html
```

`import` 会自动重算派生字段：`delta`（26届−25届）、`tier`（难度档）、`dirName`、`region`。改了分数，难度档自动跟着变。

需全量重采（如 27 届分数线公布后）时，重新采集写入 `data/*.json`，再跑：

```bash
python build.py && python build_html.py
```

**专业库数据（研招网目录 + 掌上考研明细）重采：**

```bash
# 1) 研招网全量专业目录（33MB CSV，下载地址见 build_catalog.py 头部注释）
python build_catalog.py                 # _data/majors_yzw.csv -> catalog.json

# 2) 掌上考研：全量学校 -> 专业列表 -> 专业详情（约 5.2 万次请求，本机直连约 30 分钟）
python fetch_kaoyan.py                  # -> kaoyan_api/{schools.json,plans.jsonl,details.jsonl}
python build_kao.py                     # -> kao.json

# 3) 生成 index.html（catalog + kao 会自动合并 gzip+base64 内联）
python build_html.py
```

`fetch_kaoyan.py` 支持**断点续传**（已抓到的 plan_id 不重复抓），网络中断后直接重跑即可。默认直连（`api.kaoyan.cn` 未被墙）；若需走代理，`set KAOYAN_PROXY=http://127.0.0.1:端口`。

### 3. 安卓离线 App

APK 内已内置全部数据，**装完断网也能查**。最低支持 Android 7.0（API 24）。

自行编译：

```bash
# 准备：JDK 17+，Android SDK（platform-tools / platforms;android-34 / build-tools;34.0.0）
#   修改 build_apk.py 顶部的 SDK 路径
python build_apk.py
```

脚本走的是 `aapt2 → javac → d8 → zipalign → apksigner` 纯命令行链路，**不需要 Gradle 和 Android Studio**，SDK 只需约 250MB。

> 已知坑：JDK 21+ 编译出的**匿名内部类**会让 d8 8.2 抛 `NullPointerException`。工程里已把 `WebViewClient` 写成独立顶层类规避，改代码时请沿用这个写法。

## 数据来源与声明

数据来自各高校研究生招生网、各学院《2026 年硕士研究生复试录取工作细则》、中国研究生招生信息网等公开渠道，部分院校未能获取院系级分数线的已如实留空。

- **专业目录**（「专业库」页，**1047 校 × 1,483 专业代码 × 42,823 条**）＝ **研招网（yz.chsi.com.cn）硕士专业目录**（2026 届，919 校 × 1,336 代码 × 37,722 条）经开源项目 [freecho/yzw](https://github.com/freecho/yzw) 汇总为 CSV 后聚合，**再与掌上考研公开数据取并集**（由 `merge_catalog.py` 合并校名写法差异并补入 128 所独有院校、5,101 条独有专业）；含院系、学位类型、学习方式、拟招生人数、考试科目。**拟招生人数以各校官方简章为准**。
- **复试线 · 逐年招生人数 · 考试科目 · 参考书 · 院校层次**（930 校 / 51,376 条，其中复试线 43,410 条）来自**掌上考研（www.kaoyan.cn）公开接口**（`api.kaoyan.cn` 的 `schoolList` / `planListV2` / `planDetailV2`，无需鉴权），由本仓库 `fetch_kaoyan.py` 全量采集、`build_kao.py` 聚合成 `kao.json`。数据为该校该专业**官方招生目录**的整理结果，采集于 2026-10，**招生人数与考试科目以目标院校当年官方简章为准**；`min_score` 为该校该专业最近一届复试分数线（含年份标注）。
- **国家线**（各专业每年的 A/B 区总分与单科线，2021–2026）为教育部公布的**真实数据**。
- **初试线、录取最低分、统考名额、数学科目、调剂情况**为采集自官方 / 院系官网的真实锚点（逐条标注 `source`）。
- **各科分数线**（政治 / 英语 / 数学 / 专业课）为按总分估算的**参考值**，用于直观呈现每个专业每科的大致分数段与国家单科线对照；**逐人录取名单暂未公开采集，故 App 不再提供示例数据，仅展示真实录取最低分**（字段为空时显示「—」，绝不用复试线顶替）。App 内「我的 → 数据说明」已显式标注。
- **报录比**（`majors_raw/*.txt` → `majors.json`）为各校研招办公布的**真实**「报考人数 / 录取人数」数据，覆盖 **2024 / 2025 / 2026 多届**（有数据即收录，缺届显示采集提示），逐校逐届标注来源链接，报录比按「报考 ÷ 录取」计算。目前收录 **5 所**（电子科技大学、南京邮电大学、杭州电子科技大学、北京邮电大学、东南大学）共 **9 个学校-年份、755 条**全校分专业报录数据（东南大学为全校所有专业，其余为电子信息类为主的全部招生专业），**未收录的院校 / 届次不做任何估算，只显示采集提示**。口径提醒：表内「录取人数」通常含推免，故该报录比偏乐观；非全日制专业常因调剂而出现「录取 > 报考」。
- 院校名称、专业代码均以研招网 / 学校当年招生目录为准；如与官方发布不一致，以官方为准。

本表用于横向比较和圈定目标范围。报考请以目标院校当年招生简章与官方公告为准。
